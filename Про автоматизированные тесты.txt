Автоматическое тестирование (Jest) (Общая информация)

1) Фреймворк: Jest + Supertest
Всего тестов: 41
Прохождение: 100% ✅
Время выполнения: ~2 секунды

2) Структура тестов
Файл			Количество тестов	Что тестирует
auth.test.js		11			Регистрация, логин, валидация паролей
auth-working.test.js	6			Функциональные тесты авторизации
tracks.test.js		13			CRUD треков, фильтрация, поиск, загрузка
playlists.test.js	9			Создание, редактирование, удаление плейлистов
admin.test.js		3			Управление пользователями, права доступа
simple.test.js		1			Проверка работоспособности Jest

3) Покрытие функционала
Модуль			Проверяемые сценарии
Аутентификация		Успешная регистрация, вход, обработка ошибок (короткий пароль, несовпадение, существующий email)
Треки			Получение списка, фильтрация по жанру, поиск, загрузка MP3, получение аудио, счётчик прослушиваний
Плейлисты		Создание, получение, обновление, удаление, добавление/удаление треков
Права доступа		Проверка ролей (слушатель, артист, администратор), защита эндпоинтов

Пример теста (регистрация)
javascript
test('✅ Успешная регистрация', async () => {
  const res = await request(app)
    .post('/api/auth/register')
    .send({
      username: 'testuser',
      email: 'test@example.com',
      password: '123456',
      confirmPassword: '123456'
    });
  
  expect(res.statusCode).toBe(201);
  expect(res.body.success).toBe(true);
});

4) Запуск тестов
npm test (Если в package.json прописан скрипт "test": "jest --runInBand --verbose --forceExit")
ИЛИ 
npx jest --runInBand --verbose --forceExit
