Структура ветки Backend:
```
├── backend/                          
│   ├── .env                          # Переменные окружения (JWT_SECRET, БД)
│   ├── .gitignore
│   │
│   ├── db.js                         # Подключение к MySQL (pool)
│   ├── server.js                     # Точка входа (запуск сервера)
│   │
│   ├── middleware/
│   │   └── auth.js                   # JWT аутентификация
│   │
│   ├── routes/                       # API эндпоинты
│   │   ├── auth.js                   # Регистрация, логин, /me
│   │   ├── tracks.js                 # CRUD треков, модерация, популярные
│   │   └── playlists.js              # CRUD плейлистов, треки в плейлистах
│   
│   └── node_modules/                 # Зависимости (npm)
```
